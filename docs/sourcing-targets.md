# Sourcing Targets

Rule: only recommend publishing products scoring `75/100` or higher after supplier terms, shipping, returns, margin, product photos, and fulfillment workflow are confirmed.

Scoring categories: visual appeal, margin potential, giftability, bundle fit, shipping simplicity, return risk, uniqueness, golf identity, price point, supplier reliability. Each is scored 1-10.

## Publishing Safety

Do not publish if any of these are missing:

- supplier terms
- shipping timing
- return policy
- margin
- product photos
- fulfillment workflow
- compliance clarity
- Shopify checkout compatibility
